## 2. 💳 Credit Card Fraud Detection

**Type:** Supervised Learning — Classification

Detect fraudulent credit card transactions while handling severe class imbalance.

### Key Concepts

* Exploratory Data Analysis
* Binary classification
* Class imbalance
* Class weighting
* `scale_pos_weight`
* Logistic Regression
* Decision Trees
* Random Forest
* Gradient Boosting
* AdaBoost
* XGBoost
* Confusion Matrix
* Precision
* Recall
* F1-Score
* ROC Curve
* ROC-AUC

### Best Result

**XGBoost**

* Precision: **90.00%**
* Recall: **82.65%**
* F1-Score: **86.17%**
* ROC-AUC: **97.16%**

[View Project →](./Credit%20Card%20Fraud%20Detection/)
